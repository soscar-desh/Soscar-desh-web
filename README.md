# Personal Website (Single-page Dark Theme)

This repo now contains a single-page dark-themed personal site of sheryl mwende. About and Contact content have been consolidated into `index.html` as anchored sections (`#about`, `#projects`, `#contact`).

Files now:
- `index.html` — single-page website with Hero, About, Projects, Contact sections
- `css/styles.css` — used to set the dark theme and layout styles (responsive)
- `js/script.js` — navigation handling (smooth scrolling, active link eg . email link ) and contact information
- `images/profile.png` & `images/about.jpg` — placeholders (profile for Sheryl Mwende). Save your About photo to use it on the site.
